# Adventure Works: Interactive Sales Reporting & User Engagement Analysis

📊 **Project Overview**

This project focuses on building advanced report interactivity and user engagement features in Power BI Desktop for executive stakeholders. Designed for the CEO of Adventure Works, the dashboard implements drillthrough functionality, dynamic slicers, and bookmarks to highlight key seasonal sales insights—specifically focusing on Mountain Bike product category performance leading into the end of Q1.

🎯 **Problem Said & Strategic Impact**

Static dashboards limit a CEO's ability to explore underlying data and test hypotheses. This project resolves that limitation by:
* **Enabling Granular Data Exploration:** Implementing drillthrough functionality allows stakeholders to transition seamlessly from high-level monthly summaries down to detailed customer location and order revenue tables.
* **Streamlining Visual Filtering:** Adding product category slicers gives leadership instant control over category-specific insights without needing multiple report pages.
* **Preserving Critical Insights:** Utilizing custom bookmarks captures specific analytical states—such as March Mountain Bike revenue peaks—allowing executives to reload key findings instantly with a single click.

🛠️ **Tools & Skills Demonstrated**
* **Power BI Desktop:** Configuring drillthrough targets, managing data hierarchies, setting up interactive slicers, and creating report bookmarks.
* **Executive Data Storytelling:** Structuring navigation pathways to deliver immediate, high-impact business insights to senior leadership.
* **Business Analysis:** Quarterly KPI tracking, product category trend analysis, and sales performance evaluation.

📂 **Repository Structure**
* `Creating_an_interactive_report.pbix` - The complete Power BI report file featuring configured drillthroughs, slicers, and bookmarks.
* `Screenshots/` - Visual exports of the interactive dashboard pages and bookmarked states.
